# 🚗 Electric Vehicle Sales Analysis – India

This project analyzes **Electric Vehicle (EV) sales across Indian states** to uncover adoption trends, regional performance, vehicle category dominance, and growth opportunities.  
It includes **key performance indicators (KPIs)** and **dashboard-ready visualizations** for business, policy, and strategy decision-making.

---

## 📊 Project Objective

The goal of this project is to:
- Understand **EV adoption trends over time**
- Compare **state-wise EV performance**
- Analyze **vehicle category and class contribution**
- Identify **high-growth and low-adoption regions**
- Build **executive-ready KPIs and dashboards**

---

## 📁 Dataset Information

- **Source:** Electric Vehicle Sales by State in India
- **Granularity:** Monthly / Yearly
- **Key Fields:**
  - State
  - Date (Month / Year)
  - Vehicle Category (2W, 3W, Cars, Buses, etc.)
  - Vehicle Class / Type
  - EV Sales Volume

---

## 🔑 Key KPIs

| KPI | Description |
|---|---|
| Total EV Sales | Total number of EVs sold |
| YoY Growth % | Year-over-year sales growth |
| MoM Growth % | Month-over-month growth |
| Active States Count | States with EV sales > 0 |
| Top State by Sales | Highest EV-selling state |
| Fastest Growing State | Highest YoY growth |
| 2-Wheeler Sales Share | % contribution of EV 2W |
| Commercial EV Share | Fleet & commercial adoption |
| Avg Monthly Sales | Baseline demand metric |
| Top Vehicle Category | Leading EV segment |

## 📌 Key Insights

- EV adoption is **highly concentrated** in a few states.
- **Two-wheelers dominate** total EV sales, driving mass adoption.
- Several states show **low volume but high growth**, indicating future opportunities.
- Commercial EV penetration highlights **fleet electrification trends**.
